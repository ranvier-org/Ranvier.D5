# Reference fixtures

Generate planar identity references with `node identity.mjs`: twelve point/inverse cases and forty seeded clipped polygons use d3-geo 3.1.1. A separate unchanged reflected-hole counterexample records D3 emitting area 416 instead of the correct 384 when its clip boundary encloses a reflected hole. D5 normalizes simple exterior winding before clipping and preserves the hole; the independent filled-area regression is authoritative for that discrepancy.

Run `npm ci` then `npm run generate` here. Dependencies are exact-version locked; Node/D3 are development-only and never enter a D5 package. Fixture metadata records versions, seed, coordinate conventions and numeric tolerance. Each reference package's copyright/license is copied into `licenses/` during generation. Handwritten invariant tests remain authoritative for D5-specific contracts (typed errors, immutable state, invalid inputs and ownership).

Generate spherical D3 references with `node spherical.mjs` and point-projection references with `node projections.mjs`. Generate antimeridian stream references with `node seam-streams.mjs`; these check fragment topology and endpoints without requiring identical adaptive subdivision vertices. The projection fixture records orthographic visibility separately: D3's direct point function bypasses its stream clipping, while D5's point API omits the hidden hemisphere. For independent near-antipodal interpolation references, install `python -m pip install -r precision-requirements.txt` and run `python spherical-precision.py`. The latter pins mpmath 1.3.0 at 80 decimal digits; its license is included in `licenses/mpmath.txt`. D3 fixtures remain unchanged so differences caused by its near-antipodal numerical conditioning remain visible.

The pinned d3-geo length stream omits polygon closing edges: its octant fixture reports pi radians for three quarter-circle edges. D5's documented boundary-length contract includes every closing edge (3*pi/2 for that octant). Keep the original reference data unchanged and use the hand-derived boundary tests for polygon length. Area comparisons use the fixture winding directly rather than passing it through the RFC winding adapter.

Centroid polygon edge weights use the full shortest-arc angle. The pinned D3 centroid uses asin of the cross-product norm on rings, which folds angles greater than ninety degrees. D5 has an independent wide-octant test (120-degree equatorial edge) using the oriented-normal formula, alongside unchanged small-edge reference fixtures. Centroid accumulators rescale angular weights to preserve very small finite line directions instead of underflowing their weighted components.

Generate twelve hemisphere, rectangular and Mercator line stream references with `node clipped-streams.mjs`. Mercator intersections use the combined adaptive precision tolerance because D3 clips after resampling whereas D5 clips the spherical latitude band before projection. Analytic hemisphere intersections use a 1e-9 endpoint tolerance; rectangular intersections allow the combined half-unit adaptive precision of both implementations. Independent tests enforce exact rectangular boundaries, disconnected reentry, degenerate touches and budget exhaustion.

Generate polygon stream references with `node polygon-streams.mjs`. 158 cases cover holes, complements, seam contacts, hemisphere containment, forty seeded rotated polygons, a rectangular viewport for each of the original fifty spherical cases, and 58 Mercator variants including polar caps and complements. Compare ring topology and oriented filled area using a perimeter-based bound from the combined screen precision; a relative-area tolerance is inappropriate for thin clipped slivers. The seed is 42 and d3-geo remains pinned to 3.1.1.
